# Production Workbench

Replace everyday desktop modal/Sheet workflows with one stable contextual surface.

Modes: Part, Composer, Cast, Music, Asset, Health, Mix/Export and technical evidence.

Part default sections: Text, Takes, Captions, Details.

Text: canonical editorial script + revision, selected Take wording with Original/Spoken/Tagged/Provider returned, exact used marker, Copy, Compare; never all long versions stacked.

Takes: creative stack, not history table. Show selected/current, Voice, exact method, capability, text input version, duration, exact cost, created time, outdated/fidelity state, Play, Use Take. Generating Take can coexist with ready selected Take. No auto-promotion.

Captions: source language, current/stale, SRT/VTT/JSON, download, translations, durable Jobs, confirmation/review. Global Subtitles remains for standalone/external audio.

Details: provider, region, exact model, capability, binding/reference when relevant, Part revision, Take IDs, provider attempt evidence, usage, cost basis, diagnostics.

Clicking another Part updates Workbench in place and preserves Canvas location.

If Composer Draft is saved, user may inspect elsewhere and return. If save fails/conflicts, do not discard; keep editing or Retry.

Conflict keeps local proposed text, shows baseline/current revision, allows safe reload/copy, never silent overwrite.
