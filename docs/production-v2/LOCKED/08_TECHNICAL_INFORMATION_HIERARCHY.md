# Technical information hierarchy

Do not hide legitimate technical truth.

Level 1 always visible where creatively relevant: Voice/avatar, Cast Role, model family, tier, capability, output language, selected Take, text input version, duration, captions, relevant spend.

Level 2 one click/Workbench: provider, region, exact model ID, exact method, Voice Reference, binding, Part revision, Take source snapshot, cost basis.

Level 3 deep evidence: provider attempt ID, request IDs, raw usage, diagnostics, endpoint, price version, reconciliation evidence.

Progressive disclosure means right depth at the right place, not deleting information to make UI clean.
