# Sequence and long-production productivity

Sequence is default editorial view. Future Timeline is another view of the same domain.

Sticky Sequence Toolbar: Sequence/Timing switch, Part count + duration, Search/Jump, Issues, Add.

Insertion seam is in document flow. Idle subtle; hover/focus `+ Add`; menu Speech/Silence/Venture audio; Music excluded; collision-aware Popover/Dropdown; bottom seam has real Player clearance; final affordance `+ Add another Part`.

Search/Jump for large Productions: script, Cast Role, Voice, Part number. Useful filters: Drafts, Issues, Cast role, No captions. Prefer client-side filtering when Parts already loaded.

Design SpeechPart to allow future comfortable/compact density; implement comfortable first unless authorized otherwise.

Distinguish bulk selected, Workbench active, playing and keyboard focus.

Keep non-drag reorder alternatives. Drag only if real benefit.

Long Production page is acceptable. Do not virtualize by default because variable height, inline Composer and spatial memory matter. Profile first.

Today Timing is lightweight read-only. Future Naomi can replace/enrich Timing slot without owning Part/Take/Cast/Composer/Player truth.
