# Desktop Production spatial architecture

Production v2 has four stable spatial concepts: Production Focus Bar, Production Canvas, contextual Production Workbench, Floating Transport.

Workbench closed: Canvas receives nearly full workstation width. Workbench open: default intent Canvas roughly 55–65%, Workbench 35–45%; draggable splitter; Workbench min about 420 px, comfortable default 520–600 px, max about 60%; remember operator width locally.

Production Focus Bar: approximately 52–56 px, retaining return to Work, Project/Series context, Production name, Part count, duration, historical generation spend, Health count, Cast, Preview, Mix/Export and overflow. No hero card.

Canvas owns primary page scroll. Order: optional compact Cast Reel; compact Music Bed Lane; sticky Sequence Toolbar; Sequence; final insertion; enough bottom clearance for Floating Transport.

Workbench is one stable region with modes Composer, Part, Takes, Captions, Cast, Music, Asset, Health, Mix/Export, technical evidence. Everyday desktop tasks do not use Sheets.

Floating Transport is a compact console centered over the Canvas, not the full viewport when Workbench is open; roughly 560–680 px; may grow upward with caption bubble.

Scroll ownership: Canvas main Production scroll; Workbench independent contextual scroll; script editor only its own allocated viewport; Floating Transport fixed; media explorer/dialog temporary modal scroll. Avoid page → panel → form → textarea nested scrolling.
