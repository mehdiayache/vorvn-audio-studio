# Locked domain invariants

Do not redesign these concepts during Production v2.

Work hierarchy: Venture → Project → optional Series → Production.

Narrative: Venture Persona → Production Cast Role → Speech Part. Cast is optional; no-Cast Production is first-class.

Voice: Voice Identity → durable Voice References → exact Provider/Model Bindings.

Production truth: Part = canonical editorial truth; CompositionDraft = recoverable preparation truth; Job = durable execution truth; ProviderAttempt = provider/spend evidence; Take = immutable generated performance; Player = playback only.

Generation rules: exact route explicit; `binding_id` XOR `catalogue_voice_id`; capability explicit when genuinely multimode; language never routes; no silent fallback; no first Voice or route auto-selection; Recast future-only; Takes immutable; Part exists before provider call; old selected Take remains playable while a new one generates; new Take never auto-selects; outdated selection explicit; ambiguous review-only; safe cost confirmation distinct; closing Composer never cancels Job; Player/Job remain outside Composer.

Music is parallel to narration, never a sequential Part.

Silence is editorial timing with no Voice, Take, provider operation or generation cost.

Reusable Intro/Outro/Stinger remain linked Venture assets; missing linked source is explicit and blocks faithful preview/export.

Production preview represents actual current mix including Music. Historical exports remain immutable. Generation spend is not export cost.
