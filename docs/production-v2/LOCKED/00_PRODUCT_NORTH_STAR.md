# Product north star

Production is the primary Audio Studio workstation. It must support three simple recordings, long narration, character-driven productions, conversations represented through ordinary Cast + Parts, linked Venture audio, silence, one parallel Music Bed, many Takes per Speech Part, captions/translations, local preview/export, future advanced temporal editing and future SFX/effects.

The interface must remain understandable to a teammate who has never read technical documentation.

A new teammate must be able to answer from the interface alone: What Production am I in? Which Project/Series? How long? How much generation spend? Who speaks this Part? Which Voice performs it? Which exact recording method/model? What text is canonical? What text did the selected Take actually use? Is the Take ready/generating/outdated/failed/review? How many Takes? Which is selected? Are captions current? What am I hearing? Where will new Speech be inserted? What happens when I click Generate?

If these answers require Activity, memory of previous screens, or backend knowledge, Production UX is not finished.

> Complexity remains inside Audio Studio, not inside the operator's memory.

Visual direction: white/light, calm, precise, spatial, software-like, information-rich without dashboard clutter, strong typography, technical data designed intelligently, no decorative gradients or AI-app clichés.

Production is deliberately desktop-oriented for hours of continuous work. Spatial memory matters: persistent header location, Canvas, Workbench and Player.
