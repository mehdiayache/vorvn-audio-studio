How this works

Three levels, and each one holds exactly one kind of thing.

Venture — a business or a brand. Heartsnotes. It holds projects.

Project — a channel, a show, a product. YouTube. It holds Productions.

Production — one finished piece. Ep 3 — The Lighthouse. This is where recordings live: a numbered sequence with gaps, which plays in order and stitches into one file.

Anything you make from the Speak tab without choosing a place lands in Unsorted, and you file it later.

Settings, top right, is where the name, picture, description, where it lives and deleting all live.

Silence inserts a timed gap. It costs nothing and is what makes a sleep guide breathe.

Stitch all joins every part in order into one file.

What these files are

      

        SRT is a captions file — the words plus the second each one appears.
        Drag it into a video editor and the captions land perfectly timed.


        VTT is the same thing for websites.


        Lines wrap at 42 characters over two rows — the standard readable limit —
        and cues under 0.8 seconds are stretched where there's room.

Limits worth knowing

      

        Text is sent in chunks of 500 characters — the API
        caps a single request at 600. Splitting happens at sentence ends, so it's
        seamless.


        The performance direction is capped at 100 characters by the model.
